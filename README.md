# Барбершоп — система онлайн-записи

**Школа 21 · В процессе выполнения**

## О проекте
Система для сети барбершопов, которая автоматизирует онлайн-запись, ведение расписания, отправку уведомлений, учёт оплаты и сбор обратной связи.

## Что сделано
- Проанализировала стейкхолдеров, бизнес-процессы as-is/to-be и потребности пользователей.
- Разработала 6 BPMN-диаграмм бизнес-процессов: от записи на приём до оплаты и сбора обратной связи.
- Подготовила User Story с критериями приёмки, тестовыми сценариями и Use Case с основными и альтернативными потоками.
- Спроектировала UML-диаграмму классов на 12+ сущностей, CRUD-матрицу.
