| UC-6. Просмотреть отзывы о выполненных услугах |                                                                                                                                                                                                                                                                                                                                          |
|------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Поле                                           | Описание                                                                                                                                                                                                                                                                                                                                 |
| Основное действующее лицо                      | Мастер инициирует взаимодействие с системой и получает бизнес-ценность - понимание качества своей работы.                                                                                                                                                                                                                                |
| Роль и потребность                             | Мастер хочет видеть отзывы о своей работе, чтобы понимать качество обслуживания без обращения к менеджеру.                                                                                                                                                                                                                               |
| Назначение                                     | Обеспечить мастеру самостоятельный просмотр отзывов о своей работе.                                                                                                                                                                                                                                                                      |
| Scope                                          | Чёрный ящик: результат - список отзывов по услугам мастера за запрошенный период.                                                                                                                                                                                                                                                        |
| Заинтересованные стороны                       | Менеджер - заинтересован, чтобы мастер видел отзывы самостоятельно.<br>Клиент - заинтересован в повышении качества услуг благодаря доступной мастеру обратной связи.                                                                                                                                                                     |
| Предусловие                                    | Мастер авторизован; существует хотя бы один отзыв по оказанным услугам; мастер открыл сайт барбершопа.                                                                                                                                                                                                                                   |
| Триггер                                        | Мастер выбирает действие «Отзывы на услуги».                                                                                                                                                                                                                                                                                             |
| Основной сценарий                              | 1. Мастер открывает «Отзывы на услуги» и указывает период.<br>2. Система проверяет наличие данных за период.<br>3. Система формирует список отзывов.<br>4. Система показывает мастеру список отзывов.                                                                                                                                    |
| Альтернативный сценарий                        | 2а. На выбранный период отзывов нет:<br>2а1. Система сообщает, что отзывов за период нет.<br>2а2. Мастер выбирает другой период; возврат к шагу 1.                                                                                                                                                                                       |
| Дополнительные сценарии                        | При выборе отзыва после шага 4 выполняется UC-7 «Просмотреть карточку записи на услугу»; затем мастер возвращается к списку отзывов (шаг 4).<br>Если оценка ниже установленного порога, система предлагает UC-8 «Отметить отзыв как рассмотренный». После завершения UC-8 независимо от решения мастера сценарий продолжается на шаге 4. |
| Дополнительно - интерфейс                      | Раздел «Отзывы на услуги».                                                                                                                                                                                                                                                                                                               |
| Дополнительно - бизнес-правила                 | Порог оценки, при котором отзыв считается низким.                                                                                                                                                                                                                                                                                        |
| Связанные UC                                   | UC-7 - в исходном описании обозначен как include. UC-8 - extend, расширяет UC-6 для отзывов с низкой оценкой.                                                                                                                                                                                                                            |
| Минимальные гарантии                           | Просмотр не изменяет состояние отзывов.                                                                                                                                                                                                                                                                                                  |
| Гарантии успеха                                | Мастеру предоставлен актуальный список отзывов по его услугам с оценками и комментариями.                                                                                                                                                                                                                                                |
