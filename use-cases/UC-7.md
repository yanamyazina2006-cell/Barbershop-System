| UC-7. Просмотреть карточку записи на услугу |                                                                                                                                                                                                                                            |
|---------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Поле                                        | Описание                                                                                                                                                                                                                                   |
| Основное действующее лицо                   | Мастер не инициирует UC напрямую - переходит из UC-5 или UC-6, выбирая конкретную запись.                                                                                                                                                  |
| Роль и потребность                          | Мастер хочет увидеть полную информацию по одной конкретной записи.                                                                                                                                                                         |
| Назначение                                  | Предоставить мастеру информацию по конкретной записи и отзывы о своей работе без обращения к менеджеру.                                                                                                                                    |
| Scope                                       | Чёрный ящик: результат - полная информация по выбранной записи.                                                                                                                                                                            |
| Заинтересованные стороны                    | Менеджер - заинтересован в полной информации во всех разделах без расхождений между экранами.<br>Клиент - заинтересован в точности данных о своей записи, доступных мастеру.                                                               |
| Предусловие                                 | Мастер авторизован; существует запись на услугу.                                                                                                                                                                                           |
| Триггер                                     | Мастер открывает конкретную запись из расписания или отзыва.                                                                                                                                                                               |
| Основной сценарий                           | 1. Мастер открывает запись из расписания или отзыва.<br>2. Система подтверждает существование выбранной записи.<br>3. Система собирает полную информацию о клиенте.<br>4. Система показывает мастеру карточку записи с полной информацией. |
| Альтернативный сценарий                     | 2а. Выбранная запись не найдена (удалена или перенесена):<br>2а1. Система сообщает, что запись недоступна.<br>2а2. Мастер возвращается к списку, из которого выбирал запись.                                                               |
| Поток исключений                            | Отдельный поток исключений в исходном описании не выделен.                                                                                                                                                                                 |
| Минимальные гарантии                        | Просмотр не изменяет данные записи.                                                                                                                                                                                                        |
| Гарантии успеха                             | Мастеру предоставлена полная информация о выбранной записи.                                                                                                                                                                                |
| Связанные UC                                | Вызывается из UC-5 «Просмотреть расписание записей» или UC-6 «Просмотреть отзывы о выполненных услугах».                                                                                                                                   |
