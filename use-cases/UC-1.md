| UC-1. Актуализировать расписание услуг мастера |                                                                                                                                                                                                                                                                                                                                      |
|------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Поле                                           | Описание                                                                                                                                                                                                                                                                                                                             |
| Основное действующее лицо                      | Менеджер инициирует взаимодействие с системой и получает бизнес-ценность - актуальность расписания под его ответственностью.                                                                                                                                                                                                         |
| Роль и потребность                             | Менеджер хочет быстро и без ошибок поддерживать достоверный перечень услуг и график работы мастеров, не тратя время на ручное согласование.                                                                                                                                                                                          |
| Назначение                                     | Обеспечить актуальный перечень услуг каждого мастера и период его работы как основу записи клиентов и планирования нагрузки точки.                                                                                                                                                                                                   |
| Scope                                          | Полупрозрачный ящик: действия менеджера и системы на уровне бизнес-логики - ввод данных, проверка корректности, сохранение; без технических деталей хранения и валидации.                                                                                                                                                            |
| Заинтересованные стороны                       | Менеджер - заинтересован в актуальности расписания услуг и графика работы мастеров.                                                                                                                                                                                                                                                  |
| Предусловие                                    | Менеджер авторизован с правами управления расписанием; мастер зарегистрирован; в системе ведётся каталог услуг барбершопа.                                                                                                                                                                                                           |
| Триггер                                        | У менеджера возникла необходимость изменить сведения об услуге мастера или время его работы.                                                                                                                                                                                                                                         |
| Основной сценарий                              | 1. Менеджер выбирает мастера.<br>2. Передаёт перечень услуг мастера и период его работы (дни, часы).<br>3. Система проверяет соответствие каталогу услуг и отсутствие противоречий в графике.<br>4. Система изменяет и сохраняет перечень услуг/график работы.<br>5. Система подтверждает изменение и показывает обновлённые данные. |
| Альтернативный сценарий                        | 3а. Данные не соответствуют требованиям.<br>3а1. Система сообщает причину и возвращает менеджера к предыдущему шагу.<br>3а2. Менеджер прекращает UC или пробует снова.                                                                                                                                                               |
| Поток исключений                               | 2а. Менеджер прерывает ввод до сохранения.<br>2а1. Система отменяет несохранённые изменения.<br>2а2. UC завершается без изменения расписания; действует минимальная гарантия.                                                                                                                                                        |
| Минимальные гарантии                           | Ранее сохранённое расписание услуг мастера не повреждено и не теряется при успешном или неуспешном завершении UC.                                                                                                                                                                                                                    |
| Гарантии успеха                                | Изменения услуг мастера или времени его работы сохранены, доступны мастеру и являются основанием для формирования свободных слотов записи клиентов.                                                                                                                                                                                  |
| Связанные UC                                   | UC-1 - самостоятельный основной вариант использования для управления расписанием.                                                                                                                                                                                                                                                    |
