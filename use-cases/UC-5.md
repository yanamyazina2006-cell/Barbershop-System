| UC-5. Просмотреть расписание записей |                                                                                                                                                                                                              |
|--------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Поле                                 | Описание                                                                                                                                                                                                     |
| Основное действующее лицо            | Мастер инициирует взаимодействие с системой и получает бизнес-ценность - расписание своего дня/недели.                                                                                                       |
| Роль и потребность                   | Мастер оказывает услуги и хочет видеть полный и актуальный перечень слотов без звонка менеджеру.                                                                                                             |
| Назначение                           | Обеспечить мастеру просмотр актуального расписания с записями клиентов без обращения к менеджеру.                                                                                                            |
| Scope                                | Чёрный ящик: результат - список записей мастера на запрошенный период.                                                                                                                                       |
| Заинтересованные стороны             | Менеджер - заинтересован, чтобы мастер просматривал расписание самостоятельно.<br>Клиент - заинтересован, чтобы мастер знал о записи и риск накладок снижался.                                               |
| Предусловие                          | Мастер авторизован; в системе ведутся актуальный каталог услуг и график мастера; существуют записи клиентов; мастер открыл сайт барбершопа.                                                                  |
| Триггер                              | Мастер выбирает действие «Просмотр расписания».                                                                                                                                                              |
| Основной сценарий                    | 1. Мастер открывает «Расписание» и указывает период.<br>2. Система проверяет наличие данных на период.<br>3. Система формирует список записей.<br>4. Система показывает мастеру список записей.              |
| Альтернативный сценарий              | 2а. На выбранный период записей нет:<br>2а1. Система сообщает, что записей нет.<br>2а2. Мастер выбирает другой период; возврат к шагу 1.                                                                     |
| Поток исключений                     | Отдельный поток исключений в исходном описании не выделен.                                                                                                                                                   |
| Дополнительно - интерфейс            | Раздел «Расписание» личного кабинета мастера.                                                                                                                                                                |
| Связанные UC                         | При выборе конкретной записи после шага 4 выполняется UC-7 «Просмотреть карточку записи на услугу». После завершения мастер возвращается к списку (шаг 4). В исходном описании связь обозначена как include. |
| Минимальные гарантии                 | Просмотр не изменяет состояние расписания и записей.                                                                                                                                                         |
| Гарантии успеха                      | Мастеру предоставлен актуальный список записей клиентов на его услуги за запрошенный период.                                                                                                                 |
