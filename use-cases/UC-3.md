| UC-3. Просмотреть доступные слоты по услуге |                                                                                                                                                                                                                                                                                                                                                                                                                            |
|---------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Поле                                        | Описание                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Основное действующее лицо                   | Клиент/посетитель инициирует просмотр самостоятельно либо UC автоматически вызывается внутри UC-2.                                                                                                                                                                                                                                                                                                                         |
| Роль и потребность                          | Клиент хочет увидеть доступность услуги у конкретного мастера, если он выбран, либо у всех мастеров, оказывающих услугу, до решения о бронировании.                                                                                                                                                                                                                                                                        |
| Назначение                                  | Предоставить клиенту достоверный список свободных слотов по выбранной услуге.                                                                                                                                                                                                                                                                                                                                              |
| Scope                                       | Чёрный ящик: результат - список свободных слотов, при необходимости с указанием мастера; логика сопоставления графиков и записей не раскрывается.                                                                                                                                                                                                                                                                          |
| Заинтересованные стороны                    | Менеджер - хочет, чтобы слоты отражали реальную занятость и исключали двойные записи.<br>Мастер - хочет, чтобы клиенты видели достоверный график.                                                                                                                                                                                                                                                                          |
| Предусловие                                 | В системе актуальны каталог услуг и мастеров и графики их работы; клиент выбрал услугу.                                                                                                                                                                                                                                                                                                                                    |
| Триггер                                     | Клиент запросил свободные слоты самостоятельно или в рамках UC-2.                                                                                                                                                                                                                                                                                                                                                          |
| Основной сценарий                           | 1. Клиент выбирает услугу и период без указания конкретного мастера - самостоятельно или при вызове из UC-2.<br>2. Система определяет всех мастеров, оказывающих услугу, и проверяет актуальность их графиков.<br>3. Система сопоставляет графики с существующими записями и формирует свободные интервалы по каждому мастеру.<br>4. Система показывает свободные слоты на выбранный период с указанием мастера.           |
| Альтернативный сценарий                     | 1а. Клиент указал конкретного мастера:<br>1а1. Система проверяет актуальность графика мастера на выбранный период.<br>1а2. Система сопоставляет график с существующими записями и формирует свободные интервалы.<br>1а3. Система показывает свободные слоты.<br>3а. Свободных слотов нет:<br>3а1. Система сообщает об отсутствии свободных слотов.<br>3а2. Предлагает выбрать другой период или мастера; возврат к шагу 1. |
| Поток исключений                            | Отдельный поток исключений в исходном описании не выделен.                                                                                                                                                                                                                                                                                                                                                                 |
| Минимальные гарантии                        | Просмотр не изменяет состояние расписания.                                                                                                                                                                                                                                                                                                                                                                                 |
| Гарантии успеха                             | Клиент получил актуальный список свободных слотов по услуге у выбранного мастера или у всех мастеров, оказывающих услугу.                                                                                                                                                                                                                                                                                                  |
| Связанные UC                                | UC-3 вызывается внутри UC-2 «Забронировать слот на услугу».                                                                                                                                                                                                                                                                                                                                                                |
