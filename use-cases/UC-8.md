| UC-8. Отметить отзыв как рассмотренный |                                                                                                                                                                                                                                             |
|----------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Поле                                   | Описание                                                                                                                                                                                                                                    |
| Основное действующее лицо              | Мастер получает бизнес-ценность - отреагировать на отзыв; техническим инициатором является система, предложившая отметку при просмотре негативного отзыва в UC-6.                                                                           |
| Роль и потребность                     | Мастер получил отзыв с низкой оценкой и хочет зафиксировать, что ознакомился с ним.                                                                                                                                                         |
| Назначение                             | Предоставить мастеру возможность обозначить, что он ознакомился с негативным отзывом.                                                                                                                                                       |
| Scope                                  | Чёрный ящик: результат - отзыв отмечен как рассмотренный.                                                                                                                                                                                   |
| Заинтересованные стороны               | Менеджер - заинтересован в фиксации реакции мастера, чтобы не дублировать связь с клиентом.<br>Руководитель - заинтересован в отслеживании реакции на отзывы для контроля качества сервиса.                                                 |
| Предусловие                            | Мастер просматривает в UC-6 отзыв с оценкой ниже установленного порога; отзыв ещё не помечен как рассмотренный.                                                                                                                             |
| Триггер                                | Система предлагает мастеру отметить негативный отзыв как рассмотренный.                                                                                                                                                                     |
| Основной сценарий                      | 1. Система предлагает отметить отзыв как рассмотренный.<br>2. Мастер подтверждает, что ознакомился с отзывом.<br>3. Система подтверждает выполнение действия.<br>4. Система обновляет статус на «Рассмотренный» и показывает подтверждение. |
| Альтернативный сценарий                | 2а. Мастер не подтверждает ознакомление:<br>2а1. Система оставляет исходный статус.<br>2а2. UC завершается; мастер возвращается к списку отзывов в UC-6, шаг 4.                                                                             |
| Поток исключений                       | Отдельный поток исключений в исходном описании не выделен.                                                                                                                                                                                  |
| Минимальные гарантии                   | Если мастер не отмечает отзыв, его статус не меняется, просмотр списка отзывов продолжается.                                                                                                                                                |
| Гарантии успеха                        | Мастер отметил отзыв как рассмотренный; статус доступен менеджеру.                                                                                                                                                                          |
| Связанные UC                           | UC-8 «Отметить отзыв как рассмотренный» расширяет UC-6 «Просмотреть отзывы о выполненных услугах».                                                                                                                                          |
