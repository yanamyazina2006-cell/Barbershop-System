| UC-2. Забронировать слот на услугу |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Поле                               | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Основное действующее лицо          | Клиент/посетитель инициирует взаимодействие с системой и получает бизнес-ценность - созданную запись.                                                                                                                                                                                                                                                                                                                                                                                          |
| Роль и потребность                 | Клиент хочет быстро и удобно записаться в любое время, видя услуги и свободные слоты без звонка менеджеру.                                                                                                                                                                                                                                                                                                                                                                                     |
| Назначение                         | Дать клиенту возможность выбрать услугу, мастера и слот, создать подтверждённую запись и снизить нагрузку на менеджера.                                                                                                                                                                                                                                                                                                                                                                        |
| Scope                              | Полупрозрачный ящик: бизнес-логика выбора, проверки доступности и создания записи без технических деталей реализации.                                                                                                                                                                                                                                                                                                                                                                          |
| Заинтересованные стороны           | Менеджер - хочет, чтобы записи создавались самостоятельно, особенно в пиковые часы.<br>Мастер - хочет видеть только подтверждённые записи на оказываемые услуги, без накладок.                                                                                                                                                                                                                                                                                                                 |
| Предусловие                        | В системе актуальны каталог услуг и мастеров и графики их работы; клиент открыл сайт барбершопа.                                                                                                                                                                                                                                                                                                                                                                                               |
| Триггер                            | Клиент выбирает действие «Записаться на услугу».                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Основной сценарий                  | 1. Клиент выбирает тип услуги и услугу.<br>2. Система выполняет UC-3 и показывает свободные слоты мастеров, оказывающих выбранную услугу.<br>3. Клиент выбирает слот и мастера и передаёт данные для связи.<br>4. Система проверяет корректность данных.<br>5. Система создаёт запись и закрепляет слот за клиентом.<br>6. Система подтверждает создание записи.<br>Расширение после шага 3 и перед шагом 4: если клиент авторизован и имеет право на скидку, выполняется UC-4.                |
| Альтернативный сценарий            | 1а. Клиент хочет выбрать конкретного мастера до просмотра слотов:<br>1а1. Выбирает мастера из списка оказывающих услугу.<br>1а2. Система выполняет UC-3 с выбранным мастером.<br>1а3. Сценарий продолжается с шага 3.<br>3а. Слот успел занять другой клиент:<br>3а1. Система сообщает, что слот недоступен.<br>3а2. Клиент выбирает другой слот; возврат к шагу 2.<br>4а. Данные для связи некорректны:<br>4а1. Система сообщает причину.<br>4а2. Клиент исправляет данные; возврат к шагу 3. |
| Поток исключений                   | 1b. Клиент прерывает бронирование до подтверждения на шагах 1-3.<br>1b1. Система отменяет несохранённые данные выбора.<br>1b2. UC завершается без сохранения записи; действует минимальная гарантия.                                                                                                                                                                                                                                                                                           |
| Минимальные гарантии               | Если запись не создана из-за отмены, занятого слота или некорректных данных, расписание не меняется - свободные слоты остаются свободными.                                                                                                                                                                                                                                                                                                                                                     |
| Гарантии успеха                    | Создана подтверждённая запись на выбранную услугу, к выбранному мастеру и на выбранный слот; слот закреплён за клиентом.                                                                                                                                                                                                                                                                                                                                                                       |
| Связанные UC                       | UC-3 «Просмотреть доступные слоты по услуге» - включён в UC-2. UC-4 «Применить скидку при бронировании» - расширяет UC-2.                                                                                                                                                                                                                                                                                                                                                                      |
