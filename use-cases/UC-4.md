| UC-4. Применить скидку при бронировании |                                                                                                                                                                                                                            |
|-----------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Поле                                    | Описание                                                                                                                                                                                                                   |
| Основное действующее лицо               | Зарегистрированный клиент получает бизнес-ценность - скидку; техническим инициатором является система, обнаружившая право на скидку в ходе UC-2.                                                                           |
| Роль и потребность                      | Клиент хочет автоматически получить скидку на услугу без обращения к менеджеру.                                                                                                                                            |
| Назначение                              | Определить и применить доступную скидку при бронировании и показать итоговую стоимость.                                                                                                                                    |
| Scope                                   | Полупрозрачный ящик: действия клиента и системы на уровне бизнес-логики без технических деталей реализации.                                                                                                                |
| Заинтересованные стороны                | Менеджер - хочет автоматического применения правил скидок без ручных расчётов.<br>Руководитель сети - заинтересован контролировать скидки для маркетинговых акций и удержания клиентов.                                    |
| Предусловие                             | Клиент зарегистрирован, выбрал услугу, мастера и свободный слот и находится на шаге подтверждения бронирования в UC-2.                                                                                                     |
| Триггер                                 | Система определила, что клиенту доступна скидка на выбранную услугу.                                                                                                                                                       |
| Основной сценарий                       | 1. Система подтверждает авторизацию клиента и право на скидку.<br>2. Система рассчитывает скидку по действующим правилам.<br>3. Система показывает стоимость с учётом скидки.<br>4. Клиент подтверждает применение скидки. |
| Альтернативный сценарий                 | 4а. Клиент отказывается от скидки.<br>4а1. Система сохраняет базовую стоимость без скидки.<br>4а2. UC-2 продолжается с шага 5 со стоимостью без скидки.                                                                    |
| Поток исключений                        | Отдельный поток исключений в исходном описании не выделен.                                                                                                                                                                 |
| Минимальные гарантии                    | Если клиент отказался от скидки, стоимость остаётся базовой, а бронирование в UC-2 продолжается.                                                                                                                           |
| Гарантии успеха                         | Клиенту показана и применена доступная скидка; итоговая стоимость бронирования учитывает скидку.                                                                                                                           |
| Связанные UC                            | UC-4 «Применить скидку при бронировании» расширяет UC-2.                                                                                                                                                                   |
